## Сборка и проверка на одной рабочей папке

На Node >=24.22.3 <25:

```powershell
npm.cmd ci
npm.cmd --prefix server ci --omit=dev
npm.cmd run build:release
npm.cmd start
```

Подготовка собирает веб-сайт в server/public и проверяет контрольные суммы 48 файлов релиза. Это результаты сборки, а не второй проект. Без рабочей конфигурации сервер остаётся закрытым. Включение публичной регистрации не достигается удалением проверок из закрытого сценария.

## Порядок до открытия

1. Реализовать отдельный явно включаемый режим для настоящего HTTPS-домена. Сохранять закрытый режим по умолчанию. В режиме для пользователей проверять почту, ограничивать выдачу и попытки ввода кода, исключить выдачу прав из формы или заявленного пользователем NIP. Для запроса письма и регистрации применять серверные границы и ограничения Supabase; не смешивать вход существующего пользователя и создание аккаунта.
2. На согласованном релизе подтвердить SMTP, hook, переходы и заявочный процесс; проверять статус по серверной сессии, а не искать аккаунты снаружи по адресу. Проверить одно письмо и путь от нового пользователя до подтверждённой заявки, потом новый вход, повтор, просроченный код и отсутствие доступа к чужой заявке. Не открывать весь набор кабинетов, пока не проверены реальные права, миграции и доступ.
3. Сопоставить роли с итоговым профилем. Не переустанавливать 3 сохранённых пароля без необходимости. Для отсутствующих учётных данных вводить отдельные значения только в управляющих интерфейсах базы и хостинга. Не отправлять пароли и одноразовые коды в чат.
4. Отправить проверенный коммит из основной папки в GitHub, привязать развертывание к нему, затем переключить веб-адрес, сохраняя почту и имея путь отката. Убедиться, что этот коммит обслуживает timeax.pl, а не только localhost.

Документация: [Supabase OTP](https://supabase.com/docs/guides/auth/auth-email-passwordless), [проверка до создания пользователя](https://supabase.com/docs/guides/auth/auth-hooks/before-user-created-hook), [SMTP](https://supabase.com/docs/guides/auth/auth-smtp), [домены Render](https://render.com/docs/custom-domains).
